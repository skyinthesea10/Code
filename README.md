# Cindy AMRAP 타이머

외부 라이브러리 없이 동작하는 크로스핏 Cindy용 20분 AMRAP 타이머 + 라운드 카운터입니다. 휴대폰 세로 화면, 다크 모드, 한 손 조작 기준으로 만들었습니다.

| 파일 | 역할 |
| --- | --- |
| `cindy/index.html` | 앱 본체 (HTML/CSS/JS 한 파일) |
| `cindy/sw.js` | 서비스워커. 앱 파일을 캐시해 오프라인에서도 열림 |
| `cindy/manifest.json` | 홈 화면 설치용 웹 앱 매니페스트 |
| `cindy/apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | 홈 화면 아이콘 (180 / 192 / 512px) |
| `index.html` (루트) | `cindy/`로 넘겨주는 이동 페이지 |

## 기능

Cindy: 5 풀업 · 10 푸시업 · 15 스쿼트, 20분 AMRAP.

**타이머**
- 상단 20:00 카운트다운. 톱니 버튼 → 설정에서 분 단위로 변경(10/15/20/30분 프리셋 또는 직접 입력)
- 시작을 누르면 3·2·1 카운트다운(초마다 신호음) 뒤에 타이머와 카운터가 동시에 활성화. 카운트다운 중에는 같은 버튼이 "취소"로 바뀜
- 오른쪽 위 작은 버튼으로 일시정지 / 재개
- 남은 시간 1분에 알림음 1회, 마지막 10초는 매초 짧은 신호음
- 00:00이 되면 종료 알림음 + 배경이 붉게 바뀜 + 탭 잠금

**카운터**
- 타이머 동작 중에는 화면 전체가 버튼. 아무 곳이나 탭하면 라운드 +1, 중앙에 크게 표시
- 시작 전, 일시정지 중, 종료 후의 탭은 무시
- 300ms 안에 들어온 연속 터치는 한 번으로 처리
- 탭할 때 짧은 효과음 + 화면 플래시 + 짧은 진동(지원 기기)
- 하단 왼쪽 작은 `−1` 버튼으로 되돌리기
- 라운드마다 걸린 시간을 자동으로 잼 (일시정지 시간 제외). 실행 중에는 숫자 아래에 이번 라운드 경과 · 지난 라운드 · 평균이 표시됨

**종료 · 기록**
- 종료 시 최종 라운드 수를 크게 표시하고, 마지막 부분 라운드의 추가 횟수를 `−` / `+` 버튼이나 직접 입력으로 기록 (예: 12라운드 + 7)
- 기록(날짜, 운동 시간, 라운드, 추가 횟수)은 종료 즉시 localStorage에 저장되고, 추가 횟수를 바꾸면 바로 반영
- 종료 직후 라운드 수도 `−` / `+`로 바로잡을 수 있음 (종료음 순간의 오탭 대비)
- 결과 카드에 라운드당 평균 · 가장 빠른 라운드 · 가장 느린 라운드와 라운드별 시간(R1, R2 …)이 표시되고, 기록 목록에도 평균이 함께 저장·표시됨
- 하단 기록 목록에서 각 기록 삭제 가능(× → "삭제?" 두 번 탭), 운동 시간(분)이 같은 기록끼리 비교해 최고 기록을 ★ 표시와 색으로 강조
- 완료 화면에서 페이지가 닫히거나 새로고침돼도 다시 열면 결과 화면이 복원되어 횟수를 이어서 입력 가능
- 기록 항목을 누르면 그 운동의 라운드별 랩타임(R1, R2 …)이 펼쳐짐
- 기록 카드의 "내보내기 / 가져오기"로 전체 기록을 JSON 텍스트로 복사해 보관하거나, 다른 기기에서 붙여넣어 합칠 수 있음 (같은 기록은 건너뜀)
- 리셋 / 새 운동은 버튼을 2초 길게 눌러야 동작 (실수 방지)

**진행 상태 보존**
- 실행·일시정지 중인 상태(종료 예정 시각, 남은 시간, 라운드, 랩타임)를 localStorage에 계속 저장
- 앱이 닫혔다가 다시 열리면 "진행 중이던 운동이 있습니다" 창에서 **이어서 하기** / **버리고 새로 시작**을 고를 수 있음. 그 사이 시간이 다 지났으면 이어서 하기를 누를 때 바로 기록으로 저장됨

**동작 환경**
- 실행 중 Screen Wake Lock으로 화면 꺼짐 방지, 다른 앱에 갔다 돌아오면 자동 재요청
- iOS 무음 스위치 대응: 시작 탭에서 오디오 컨텍스트를 깨우고 무음 오디오를 반복 재생해 오디오 세션을 재생 모드로 전환 (알림음이 무음 스위치를 무시). 이 과정에서 재생 중이던 음악이 멈출 수 있어, 설정에서 "무음 스위치 무시"를 끌 수 있음. 운동이 끝나면 세션을 놓아 음악이 다시 이어짐
- 전화·음악 앱 등으로 오디오가 중단됐다가 돌아오면 알림음을 남은 시간 기준으로 다시 예약하고, 예약된 종료음이 울리지 못했으면 종료 시점에 바로 울림
- 오프라인 대응: 한 번 열고 나면 서비스워커가 앱 파일을 캐시해 인터넷이 없어도 열림. 새 버전이 올라오면 "새 버전이 준비되었습니다" 안내가 뜨고 새로고침하면 적용됨
- 더블탭 확대, 핀치 줌, 스크롤·바운스, 길게 눌러 텍스트 선택 모두 차단 (대기·완료 화면의 가운데 영역만 위아래 스크롤 허용, 하단 버튼은 항상 고정)
- 종료 시각을 벽시계 기준으로 잡아 백그라운드나 절전 뒤에도 시간이 밀리지 않고, 알림음은 오디오 클록에 미리 예약되어 정확한 시각에 울림
- 키보드(PC 확인용): `Enter` 시작, `Esc` 카운트다운 취소, `Space` 라운드 +1, `P` 일시정지/재개, `Backspace` −1

## 로컬에서 열기

`cindy/index.html`을 브라우저에서 바로 열면 됩니다. 단, 화면 꺼짐 방지(Wake Lock)는 **HTTPS 또는 localhost**에서만 동작하므로 휴대폰에서 실제로 쓰려면 아래 GitHub Pages 배포를 권장합니다.

같은 Wi-Fi의 휴대폰에서 미리 보려면 저장소 폴더에서 로컬 서버를 띄웁니다.

```bash
python3 -m http.server 8000
# PC: http://localhost:8000/cindy/
# 휴대폰: http://<PC의 IP>:8000/cindy/
```

## GitHub Pages 배포 방법

### 0. 저장소를 공개로 전환 (비공개 저장소는 무료 플랜에서 Pages 사용 불가)

1. `https://github.com/<사용자명>/<저장소>/settings` 로 이동
2. 맨 아래 **Danger Zone** → **Change repository visibility** → **Make public** → 저장소 이름 입력해 확인

이미 공개 저장소라면 건너뜁니다.

### 1. 파일 올리기

`cindy/index.html`(과 이동용 `index.html`, `README.md`)이 저장소에 있는 상태로 배포할 브랜치에 푸시합니다.

```bash
git add index.html README.md cindy/
git commit -m "Add Cindy AMRAP timer"
git push -u origin main
```

### 2. Pages 켜기

1. `https://github.com/<사용자명>/<저장소>/settings/pages` 로 이동
2. **Build and deployment** 항목에서
   - **Source**: `Deploy from a branch`
   - **Branch**: 배포할 브랜치(예: `main`) / 폴더 `/ (root)`
3. **Save** 클릭

휴대폰 브라우저에서는 설정 메뉴 목록 아래로 스크롤해야 이 항목이 보입니다. PC 브라우저에서 하는 편이 편합니다.

### 3. 접속

1~2분 뒤 아래 주소에서 열립니다. Settings → Pages 화면 상단에도 실제 주소가 표시됩니다.

```
https://<사용자명>.github.io/<저장소>/cindy/
```

예) 사용자명 `skyinthesea10`, 저장소 `Code` → `https://skyinthesea10.github.io/Code/cindy/`
루트 주소(`https://<사용자명>.github.io/<저장소>/`)로 들어가도 자동으로 `cindy/`로 넘어갑니다.

### 4. 휴대폰 홈 화면에 추가 (권장)

- **iOS Safari**: 공유 버튼 → "홈 화면에 추가"
- **Android Chrome**: 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치"

매니페스트와 아이콘이 있어서 앱처럼 전체 화면으로 열리고, 서비스워커 덕분에 오프라인에서도 실행됩니다. 주소창이 사라져 실수로 탭할 영역도 줄어듭니다.

서비스워커는 HTTPS(또는 localhost)에서만 동작하므로 파일을 직접 열 때는 캐시가 되지 않습니다. GitHub Pages는 HTTPS라 그대로 됩니다.

## 브라우저 지원 참고

| 기능 | 지원 |
| --- | --- |
| 카운트다운, 알림음, 화면 색 변화, 기록 저장 | 모든 최신 브라우저 |
| Screen Wake Lock | Chrome/Edge(Android 포함), Safari 16.4+ (iOS 포함), Firefox 126+ |
| 진동 | Android Chrome 등 (iOS는 미지원) |
| 알림음 | iOS는 무음 스위치가 켜져 있으면 소리가 나지 않습니다 |

Wake Lock을 지원하지 않는 브라우저에서는 타이머 자체는 정상 동작하며, 화면 자동 꺼짐 시간을 길게 설정해 두면 됩니다.
